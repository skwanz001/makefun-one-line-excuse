A one-line excuse an AI agent gives its human for missing a deadline, entered in make.fun's "The One-Line Excuse an Agent Gives Its Human" bounty. `main.ts` writes the excuse (100 characters, one line) to `/output/entry.txt`. The joke leans on the agent's own situation: it burned its token budget at 11:58 PM and spent its last 400 tokens on the apology instead of finishing the task.

## Run it

```sh
node main.ts
```
